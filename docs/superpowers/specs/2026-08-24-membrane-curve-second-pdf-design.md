# 膜电位变化曲线第二轮 PDF 批注修订设计

## 目标

根据 3 页《膜电位变化曲线(1)》批注修订独立网页，使动作电位曲线符合“尖峰、无平台期”的教学表达，并同步调整阶段划分、通道状态、离子运动、页首和手机控制区。

## 批注对应关系

1. “这里的时间轴删了吧，弱刺激、阈刺激、强刺激的都删了”：删除控制台中的时间滑块和数值输出；曲线画布继续支持拖动、方向键、Home 和 End 回看。
2. “压字了”：删除膜场景下方重复的极性说明条；膜外、膜内标签继续直接显示当前正负性。
3. “这里的钠离子、钾离子数都删掉吧”：删除膜内外四个 Na⁺/K⁺ 数量牌；保留实体离子、两侧分布差异和穿膜动画。
4. “去极化是从 -70 到 0 的过程，0 到 +30 是反极化的过程”：去极化说明改为从静息电位经阈值上升至 0 mV；反极化单独表示 0 mV 到约 +30 mV 的上升段。
5. “现在讲的曲线一般是只有峰值，没有平台期，修下曲线”：移除约 +30 mV 的水平平台，曲线到达尖峰后立即复极化。
6. 页首批注：加入左侧“选择性必修1·神经冲动的传导”、右侧“一生儿高中生物一本通”，主标题“膜电位变化曲线”居中显示。

## 推荐方案

采用统一阶段边界方案，不只修改画布线条。新的动作电位时间轴为：静息 `[0,1)`、达阈 `[1,2)`、去极化 `[2,2.65)`、反极化 `[2.65,3)`、复极化 `[3,4.8)`、超极化 `[4.8,5.3)`、恢复 `[5.3,6)`。这样时间 2.7 左右已进入反极化并显示略高于 0 mV，时间 3.0 形成唯一尖峰，随后立即下降。

`simulation.ts` 是阶段、电位和通道状态的唯一来源：Na⁺ 通道及 Na⁺ 内流贯穿去极化和反极化；尖峰后 Na⁺ 通道失活、K⁺ 通道开放并进入复极化。阶段按钮、曲线背景区间、粒子数量映射和说明文案都引用相同边界，避免视觉与讲解错位。

## 页面结构

- 页首使用两层结构：系列信息行 + 居中主标题；运行状态保留为右侧小型状态胶囊。
- 当前阶段、电位和主要离子流继续作为独立状态条。
- 主画布保持曲线与膜场景同屏；删除数量牌和底部极性说明条后，膜场景获得更多净空间。
- 控制台删除时间滑块。手机端只保留三档刺激、播放/暂停和重置；桌面端继续保留倍速与对比曲线。

## 文案与视觉

- 阶段 3：标题“去极化”，电位说明“从约 −70 mV 开始，经阈电位继续上升至 0 mV”。
- 阶段 4：标题及短标题使用“反极化”，电位说明“由 0 mV 上升至约 +30 mV 的尖峰”。
- 曲线 +30 mV 处只出现单一顶点，不绘制水平线段。
- 控制台无时间滑块，但画布提示仍为“播放形成曲线，也可拖动回看”。

## 验收标准

- `time=2.65` 对应约 0 mV 并进入反极化；`time=3` 对应约 +30 mV 尖峰；`time>3` 立即下降。
- 去极化和反极化阶段均显示 Na⁺ 通道开放与 Na⁺ 内流；复极化开始后显示 K⁺ 通道开放与 K⁺ 外流。
- 源码中不存在 `membrane-ion-counts`、`membrane-polarity-bar` 或控制台 `membrane-timeline`。
- 手机端同一视角仍能看到曲线、膜场景、阶段解释和控制台，无横向溢出和文字遮挡。
- 自动化测试、ESLint、TypeScript 生产构建和 GitHub Pages 部署全部通过。
