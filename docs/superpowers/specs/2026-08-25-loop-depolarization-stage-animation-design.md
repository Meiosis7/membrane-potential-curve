# 去极化与反极化阶段循环动画设计

## 目标

在美化版中点击“去极化”或“反极化”阶段后，该阶段的曲线进程、Na⁺ 通道状态和 Na⁺ 穿膜动画持续循环，不再到阶段末尾后冻结。保留的原版继续使用有界分阶段播放。

## 根因

离子穿膜 CSS 动画已设置为无限循环，但阶段播放控制器到达 `playUntil` 后会调用 `setPlaying(false)`。`MembraneView` 随即给场景添加 `is-paused`，导致穿膜粒子的动画被暂停在当前帧。

## 行为设计

- 美化版分阶段播放“去极化”时，在 `2` 至 `getStagePlaybackEnd(2.65)` 之间循环。
- 美化版分阶段播放“反极化”时，在 `2.65` 至 `getStagePlaybackEnd(3)` 之间循环。
- 循环跨过阶段末尾时回到该阶段起点，保持 `playing=true`，Na⁺ 穿膜 CSS 动画不中断。
- 点击顶部或底部暂停按钮时停止循环并保留当前时间。
- 点击其他阶段时取消旧循环；其他阶段仍只播放一次并停在阶段末尾。
- 从静息状态启动全流程时不启用阶段循环，时间会连续推进到 `6`，不会在反极化阶段重复。
- 阶段循环被手动暂停后，点击“继续”恢复同一阶段循环。
- 拖动曲线、切换刺激强度和重置均取消阶段循环。

## 实现边界

- 在播放计算模块中增加可测试的区间循环计算，不修改生理阶段定义。
- 在 `MembraneCurveLab` 中用循环起点引用区分“循环阶段”和“有界阶段”。
- 不修改离子数量、通道开闭逻辑、动画速度、美术样式或原版/美化版布局。

## 验收标准

- 去极化和反极化连续运行超过各自一个阶段时长后仍为播放状态，时间仍位于对应阶段区间。
- Na⁺ 穿膜粒子在两个阶段中持续移动，不冻结。
- 暂停后粒子停止，继续后恢复。
- 全流程播放经过反极化后进入复极化。
- 其余五个阶段仍在各自末尾自动停止。
- 原版的全部阶段仍在各自末尾自动停止。
