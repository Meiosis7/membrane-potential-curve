# 膜电位美化版手机一屏适配与 8.26 批注设计

## 目标

让美化版在常见手机和短屏手机上都能在同一视角完整显示页眉、膜电位曲线、膜与离子通道、阶段说明和控制台，同时落实《膜电位变化曲线8.26.pdf》中的页眉与状态位置批注。

## 已确认问题

- 页面外壳固定为一屏并隐藏溢出内容，但短屏规则仍给曲线、膜区、阶段栏和说明区设置了合计超过可用高度的固定最小值。
- 320×568、360×640 等短屏因此必然裁掉底部阶段说明或控制台。
- 手机规则隐藏了课程系列信息，和 PDF 中“固定要求，一定要加上”冲突。
- 当前阶段和电位位于页眉右侧，PDF 要求把红圈内状态移到下方曲线区域。

## 采用方案

采用内容优先的自适应一屏布局，不允许纵向滚动，也不缩放整页：

1. 手机页眉固定为两层：上层左侧显示“选择性必修1· 神经冲动的传导”，右侧显示“一生儿 高中生物一本通”；下层居中显示“膜电位变化曲线”。
2. 手机页眉不再显示当前阶段、电位和离子流摘要；当前阶段与电位移动到曲线卡片标题区。
3. 页面主区使用按视口高度变化的 `clamp()` 行高，膜区占剩余空间；移除短屏下会累加溢出的硬编码最小高度。
4. 为浏览器安全区保留内边距，并固定文字缩放，避免带刘海、底部手势条或浏览器自动放大文字时产生裁切。
5. 在极短屏上压缩装饰性间距、次要说明和卡片内边距，但保留所有教学区域、关键文字、动画和控件。

## 布局约束

- 支持并验证 320×568、360×640、375×667、390×844、412×915。
- 六个关键区域必须同时处于视口内：页眉、曲线、膜与离子通道、阶段导航、阶段说明、控制台。
- 关键区域按上述顺序纵向排列，不能互相覆盖。
- 页面不能出现横向或纵向文档滚动条。
- 课程系列文字不能在手机规则中隐藏。
- 标题的视觉中心与视口中心保持一致。
- 桌面布局和既有播放、阶段切换、离子循环动画行为不变。

## 验证方式

- 源码契约测试：检查手机页眉固定文字、居中标题、页眉状态隐藏、曲线状态存在，以及自适应行高规则。
- 浏览器回归测试：逐一设置五种手机尺寸，验证六个区域的边界、顺序、无溢出、页眉文字可见和曲线状态可见。
- 视觉检查：重点检查最小的 320×568 和常见的 390×844，确认内容可读、控制台按钮可操作、膜与离子动画区域未被挤没。
