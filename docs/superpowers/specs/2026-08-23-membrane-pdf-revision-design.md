# 膜电位变化曲线 PDF 批注修订设计

## 目标

将 4 页《膜电位变化曲线 修改内容》中的批注逐条落实到独立网页，并保持桌面端与手机端都能在一个视角内同时看到曲线、离子通道、阶段解释和控制台。

## 已确认的修改清单

1. 页首改为系列化的紧凑标题栏，主标题使用“膜电位变化曲线”，字号加大。
2. 膜外、膜内标签缩小并避开离子、极性和底部说明。
3. 缩短膜外、膜内区域，给说明文字留出稳定空间。
4. 电位开始变化时显示刺激脉冲动画；播放暂停时动画同步暂停。
5. 去极化时不使用大箭头代替 Na⁺，而让带有“Na⁺”文字的真实粒子从膜外穿过 Na⁺ 通道进入膜内。
6. Na⁺ 内流阶段，膜外 Na⁺ 数量减少、膜内 Na⁺ 数量增加；拖动时间轴时数量与当前阶段同步。
7. 复极化、超极化和恢复阶段不使用大箭头代替 K⁺，而让 K⁺ 粒子从膜内穿过 K⁺ 通道进入膜外。
8. K⁺ 外流阶段，膜内 K⁺ 数量减少、膜外 K⁺ 数量增加；拖动时间轴时数量与当前阶段同步。
9. 去极化说明改为“Na⁺ 顺电化学浓度梯度大量内流”。

## 推荐方案

采用“粒子守恒 + 阶段同步”方案。常驻粒子使用稳定的位置模板，当前时间决定膜内外各显示多少个 Na⁺ 与 K⁺；跨膜粒子沿通道中心连续循环。这样用户暂停、回放或拖动时间轴时，粒子分布仍能准确反映当前阶段，不依赖偶然完成的 CSS 动画次数。

不采用只移动装饰点的方案，因为它不能表达两侧数量变化；不采用完整 Hodgkin-Huxley 数值模型，因为本任务是高中教学模型，额外参数会削弱单屏可读性。

## 结构与数据流

- `simulation.ts` 继续负责时间、刺激强度、阶段、电位和通道状态。
- 新增 `ion-visual-state.ts`，把当前快照映射为离子两侧数量、跨膜方向和刺激脉冲状态。
- `MembraneCurveLab.tsx` 将时间、刺激强度和播放状态传入膜场景。
- `MembraneView.tsx` 根据离子视觉状态渲染常驻粒子与跨膜粒子，不再渲染大箭头。
- `membrane-curve.css` 负责单屏布局、紧凑膜区、刺激电极脉冲和两种跨膜轨迹。

## 交互细节

- 阈刺激和强刺激在 `1.0–2.0` 时间单位出现刺激脉冲；弱刺激在局部电位阶段出现较弱脉冲。
- Na⁺ 在 `2.0–3.0` 时间单位持续内流，越接近峰值，膜内 Na⁺ 越多。
- K⁺ 在 `4.0–6.0` 时间单位持续外流，越接近恢复末段，膜外 K⁺ 越多。
- 所有粒子保留缓慢漂移；播放时跨膜粒子连续运动，暂停时停在当前画面。
- 关闭的通道保持灰色，开放通道高亮；跨膜粒子严格经过对应通道中央。

## 响应式布局

- 桌面端保持曲线与膜场景并排。
- 手机端保持曲线与膜场景上下排列，但压缩页首、膜区和步骤解释的高度。
- 膜内/膜外标签使用更小字号并固定在边角；极性信息移入独立的底部条，不与标签重叠。
- 320 px 宽度仍保留三种刺激、播放/重置和时间轴。

## 测试与验收

- 单元测试验证 Na⁺、K⁺ 数量随时间的单调变化及流动方向。
- 源码契约测试验证主标题、刺激电极、跨膜粒子和“电化学浓度梯度”文案存在，并验证旧的大箭头节点被移除。
- 运行测试、ESLint 和生产构建。
- 检查生成页面包含正确标题且 GitHub Pages 静态资源可访问。

## 可见性修订

首版实现存在“节点已渲染但用户看不出来”的问题，最终验收以可观察行为为准：

- 刺激脉冲从达到局部变化开始持续到达阈阶段结束，正常 1× 播放时至少可见 1 秒。
- 手机端跨膜离子直径不小于 30 px，文字不小于 8 px；同一通道至少有 4 个错峰粒子连续穿过整层膜。
- 跨膜路径使用发光轨迹强调通道位置，但不使用方向大箭头。
- 膜外和膜内常驻显示 Na⁺、K⁺ 数量牌；粒子跨膜时，数量牌与实体粒子的增减同步。
- 验收必须同时检查静息、刺激、Na⁺ 内流和 K⁺ 外流四个画面，不能只检查源码节点是否存在。
