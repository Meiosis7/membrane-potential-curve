# 独立磷脂双尾视觉设计

## 目标

将美化版膜中的每组磷脂绘制为两个彼此独立的磷脂：上、下各一个圆形亲水头，每个圆分别连接两条疏水尾，共四条互不粘连的线。

## 方案

- 保留现有 `.membrane-lipid-field i` 数量、布局和动画层级，不修改 React 结构。
- `i::before` 独立绘制上层磷脂的圆形头部和两条向膜中心延伸的尾链。
- `i::after` 独立绘制下层磷脂的圆形头部和两条向膜中心延伸的尾链。
- 两组尾链在膜中央保留可见间隙，不交叉、不接触，不形成一个组合图形。
- 桌面端和手机端使用相同结构，仅缩小尺寸；离子、通道、曲线及控制逻辑保持不变。

## 验收标准

- 每个可见单元有两个圆、四条独立线。
- 每个圆只连接自己的两条线。
- 上下尾链之间存在间隙。
- 390px 手机视图和 1440px 桌面视图均清晰、无溢出。
- 原有播放、分阶段动画和离子穿膜交互继续通过测试。
