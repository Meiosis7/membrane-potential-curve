# 膜电位变化曲线美化版设计规范

## 目标

在不改变现有教学内容、曲线计算、阶段播放、离子动画和手机单屏布局的前提下，新增一套“现代生物实验舱”视觉版本。现有公开页面继续作为稳定原版，美化版使用独立地址，便于比较、演示和回退。

## 版本与路由

- 原版继续保留在 `/`，公开地址仍为 `https://meiosis7.github.io/membrane-potential-curve/`。
- 美化版新增在 `/beautified/`，公开地址为 `https://meiosis7.github.io/membrane-potential-curve/beautified/`。
- 原版页面不得引入美化版选择器，不得改变当前颜色、间距、布局或动画表现。
- 两个版本共用同一套模拟、阶段文案、播放状态和离子分布逻辑，避免知识内容分叉。

## 技术结构

### 页面入口

- 保留 `app/page.tsx` 作为原版入口。
- 新建 `app/beautified/page.tsx`，加载原始基础样式及美化版覆盖样式。
- `MembraneCurveLab` 增加可选的 `visualVariant` 参数，默认值为 `original`。默认渲染的根 class 仍严格保持 `membrane-shell`；只有美化版追加 `is-beautified`。

### 样式隔离

- 新建 `models/03-membrane-potential-curve/membrane-beautified.css`。
- 所有新增规则必须以 `.membrane-shell.is-beautified` 为作用域，不允许使用会影响原版的裸选择器。
- 原始 `membrane-curve.css` 继续承担布局、响应式和可访问性基础；美化版文件只覆盖视觉表现以及与美术层级直接相关的微调。

### Canvas 主题

- `CurveCanvas` 接收与页面一致的视觉版本参数。
- 原版继续使用当前曲线、网格、背景和标记颜色。
- 美化版使用独立 Canvas 调色板与阶段光带，但坐标、曲线形状、时间拖动和可见曲线形成过程保持完全一致。

## 推荐视觉方向：现代生物实验舱

### 整体气质

- 使用偏暖的雾白底色、深墨绿色正文、青蓝色 Na⁺、琥珀色 K⁺、珊瑚红电位曲线。
- 背景加入克制的径向光晕和细微网格，不使用大面积深色，不影响课堂投屏与文字阅读。
- 卡片使用半透明浅色表面、细描边、内高光和柔和阴影，形成实验仪器面板的层级感。

### 页头与实时状态

- 系列信息保持轻量，标题成为最明确的视觉锚点。
- 当前阶段、电位和离子运动形成一条精致的数据舱，电位值使用珊瑚红强调。
- 播放状态使用小型呼吸灯，不增加额外说明文字。

### 曲线面板

- 曲线画布使用轻微青灰渐变和更细腻的坐标网格。
- 当前阶段使用柔和纵向光带，曲线主线增加克制的外发光，当前点使用双层圆点。
- 阈刺激、弱刺激、强刺激仍保持可区分的线型，不改变原有比较逻辑。

### 膜与离子面板

- 膜外使用冷青色环境层，膜内使用暖米色环境层，中央磷脂双分子层形成柔和的金色带。
- Na⁺、K⁺ 粒子保留持续漂移动画，增加玻璃珠高光和颜色边缘，不增加粒子数量。
- 通道蛋白保留现有图像素材，关闭时低饱和，开放时出现对应颜色的边缘辉光和内部通路光。
- 离子跨膜轨迹由粗亮柱调整为更细的能量通道，仍确保移动方向一眼可见。

### 阶段导航与说明

- 七个阶段按钮形成连续实验进程条，未选阶段为浅色刻度，当前阶段为青蓝色高亮并带细小进度光。
- 说明卡使用标题、关键电位、通道行为三层信息层级；不新增知识内容。

### 控制台

- 底部控制台表现为统一的浮动操作坞。
- “开始/暂停”保持唯一主按钮；刺激强度、倍速、对比曲线仍保持原交互位置和触控面积。
- 按钮使用轻微悬浮、按压反馈和明确焦点环，不使用夸张弹跳。

## 响应式约束

- 390 × 844、500 × 1082 等手机视图必须继续在一个 `100svh` 视角内显示页头、曲线、膜通道、阶段说明和控制台。
- 手机端不得出现横向或纵向页面滚动；内部区域也不设置独立滚动条。
- 手机端减少阴影半径、光晕面积和装饰网格密度，但保留完整的信息层级。
- 桌面端保持曲线与膜结构并排；手机端仍为上下排列，不改变当前教学阅读顺序。

## 动画与可访问性

- 不改变全流程和分阶段播放速度。
- 美化版可增加当前曲线点呼吸、开放通道辉光和阶段切换淡入，但所有动画只使用透明度与变换，避免布局抖动。
- `prefers-reduced-motion: reduce` 继续关闭非必要动画。
- 文本与背景对比度保持清晰，按钮触控高度和键盘焦点状态不得低于原版。

## 验收标准

1. 原版 `/` 的根元素不含 `is-beautified`，现有布局和外观不受影响。
2. 美化版 `/beautified/` 使用 `is-beautified` 且仅加载作用域内的美化规则。
3. 两个版本使用相同的模拟、阶段和播放逻辑，现有自动化测试全部通过。
4. 新增契约测试验证独立路由、样式作用域、默认原版和 Canvas 双主题。
5. 在桌面与 390 × 844 手机视图中，美化版无溢出、无遮挡、无控制台错误。
6. 实际点击全流程、去极化、反极化、复极化、超极化和恢复步骤时，曲线与离子动画均正常。
7. GitHub Pages 同时提供原版和美化版两个可直接访问的公开链接。

## 非目标

- 不修改膜电位知识内容、阶段边界和离子分布规则。
- 不重画或替换现有 AI 通道蛋白与粒子素材。
- 不增加新的控制项、教程弹窗、音效、登录或数据存储。
- 不把美化版设置为原版首页，也不删除原版。
