# 美化版磷脂双分子层与离子外观调整设计

## 目标

让美化版膜结构一眼可辨为磷脂双分子层，并去除 Na⁺、K⁺ 粒子下方的黄色填充底座感。原版页面及模拟行为保持不变。

## 设计

### 磷脂双分子层

- 美化版细胞膜显示上下两排重复磷脂单元。
- 上排亲水头朝膜外、疏水尾朝膜中央；下排亲水头朝膜内、疏水尾朝膜中央。
- 亲水头使用清楚的圆形结构，疏水尾使用成对细线，不再依赖一整块黄色带状背景表达膜。
- Na⁺、K⁺ 通道蛋白继续跨越双分子层，开闭状态与穿膜路径不变。

### 离子粒子

- 移除美化版离子的黄色实心填充、玻璃高光和厚重底座阴影。
- Na⁺、K⁺ 使用透明或近透明背景的简洁描边粒子；Na⁺ 保留青蓝识别色，K⁺ 保留暖橙识别色。
- 粒子文字保持清晰可读，普通状态与跨膜状态使用同一视觉语言。
- 不改变粒子数量、两侧分布、漂移动画、跨膜方向或动画节奏。

## 范围与隔离

- 生产修改限于 `MembraneView.tsx` 的膜装饰结构和 `membrane-beautified.css` 的美化版样式。
- 所有新样式必须位于 `.membrane-shell.is-beautified` 作用域下。
- `/` 原版 DOM、样式和行为保持不变。
- 不新增图片、第三方依赖或粒子数量。

## 验收

- 桌面、平板和手机中都能看到两排方向相反的磷脂单元。
- 膜中央为疏水尾相向区域，不再是一整块黄色底板。
- Na⁺、K⁺ 粒子无黄色实心底座，仍能清楚区分并持续运动。
- Na⁺ 内流和 K⁺ 外流粒子继续真实穿过对应开放通道。
- 原版视觉不变；现有快速测试、构建、真实浏览器回归和 GitHub Pages 子路径测试全部通过。
