# 膜电位交互模型美化版：视图布局与 UI 重构设计

## 目标

保留现有原版 `/` 完全不变，重新设计 `/beautified/` 的信息结构、视图布局和操作界面。美化版必须让学习者在同一个视角中同时理解“电位曲线如何形成”和“离子为什么这样运动”，而不是在原版布局上仅替换颜色、阴影和材质。

## 当前问题

- 美化版沿用原版 DOM 排列和卡片比例，本质上仍是同一布局换皮肤。
- 桌面端电位曲线占据约三分之二宽度，离子膜与通道视图过窄，机制动画不够突出。
- 阶段导航、阶段解释和实验控制台横向铺满页面，彼此缺少明确的操作层级。
- 手机端把桌面卡片依次纵向压缩，虽然能塞进一屏，但曲线、阶段说明和控制按钮都过小。
- 标题区、状态条、卡片标题重复表达阶段、电位和离子流，信息密度高但重点不明确。

## 选择的方案

采用“机制主视图实验台”。离子膜与通道动画是第一视觉中心；电位曲线和阶段解释组成同步观察区；阶段导航和实验控制具有稳定、清楚的位置。

未选择的方案：

- 曲线主视图：改动较小，但无法解决离子机制被弱化的问题。
- 全屏膜场景叠加浮层：视觉冲击更强，但曲线、说明和控制容易遮挡主动画，不适合教学操作。

## 桌面布局

页面固定在一个视口内，采用三层结构：

1. 顶部状态栏：保留简短标题，集中显示当前阶段、膜电位、主要离子流、运行状态，并提供主播放按钮。
2. 中部实验工作区：使用三列布局。
   - 左列为 7 个动作电位阶段的垂直导航，数字、短标题和当前/已完成状态清晰可辨；阈下局部电位只随弱刺激显示，不伪装成动作电位流程的一步。
   - 中列为面积最大的离子膜主视图，突出 Na⁺、K⁺、通道开闭、刺激脉冲、膜内外极性和真实跨膜路径。
   - 右列上方为实时形成的膜电位曲线，下方为当前阶段解释。曲线、电位、阶段原因随同一时间状态同步变化。
3. 底部控制坞：刺激强度、播放/暂停、重置、速度、对比曲线按使用频率分组。播放是唯一主按钮，其余操作保持次级视觉权重。

桌面参考结构：

```text
┌ 标题 │ 当前阶段 │ 膜电位 │ 离子流 │ 运行状态/播放 ┐
├ 阶段导航 ┬──────── 离子膜主视图 ────────┬ 电位曲线 ┤
│ 01—07   │ Na⁺/K⁺、通道、刺激、膜内外极性 │ 阶段解释 ┤
├─────────┴──────────────────────────────┴──────────┤
│ 刺激强度 │ 播放/重置 │ 速度 │ 对比曲线             │
└──────────────────────────────────────────────────┘
```

## 手机布局

目标视口为 390 × 844，必须无横向或纵向页面滚动，并保持四类教学信息同时可见。

- 顶部 52–58 px：标题缩写、当前阶段、膜电位和主播放按钮。
- 曲线区约 170–190 px：保留坐标、阈电位、逐步形成曲线和拖动回看；减少重复标题和大面积空白。
- 膜视图区占最大高度，约 330–360 px：通道蛋白和跨膜离子必须比现版更大、更容易追踪。
- 阶段区约 90–110 px：7 个动作电位阶段改为紧凑横向进度轨道；当前阶段解释只显示“变化原因 + 结果”的核心句，仍可点阶段播放。弱刺激时阶段说明可显示阈下局部电位，但不增加空白导航项。
- 底部控制坞约 74–88 px：第一行突出播放、重置和刺激强度；第二行放置速度与对比开关。

手机端不是将桌面三列简单堆叠，而是使用独立的固定视口网格。非当前阶段的长说明不占据空间，所有关键控制保持可点击。

## 组件与布局边界

- `MembraneCurveLab` 继续拥有唯一的播放、时间、刺激强度、速度和对比状态。
- 原版继续使用现有结构和样式，不改变 DOM 顺序和类名契约。
- 美化版使用独立的布局组件或明确的 variant 分支，重排相同的曲线、膜视图、阶段信息和控制，不复制模拟逻辑。
- `CurveCanvas`、`MembraneView` 和阶段内容数据仍共享；允许增加仅用于布局的包装层、显示密度参数和无行为的标题/状态组件。
- 美化 CSS 必须全部位于 `.membrane-shell.is-beautified` 作用域下，不得影响 `/`。
- 不增加新的第三方 UI 或动画依赖。

## 数据与交互同步

`time`、`snapshot`、`playing` 和 `intensity` 仍是单一事实来源：

- 播放推进时间，曲线逐段绘制，膜视图同步更新通道、离子数量和跨膜方向。
- 点击阶段导航从该阶段起点播放到边界，不允许变成静态跳转。
- 拖动曲线会暂停播放并同时更新膜视图和阶段解释。
- 弱刺激、阈刺激和强刺激继续使用现有生物学逻辑。
- Na⁺、K⁺背景粒子持续运动；开放通道时出现可见的真实穿越粒子。
- 0 mV 时膜内外均显示 `0`。

## UI 视觉系统

- 风格：现代生物实验仪表盘，而不是大面积毛玻璃卡片。
- 背景：干净的浅灰白实验台，允许极轻的网格或渐变，但不抢占内容。
- 主色：深青色用于导航和主操作；Na⁺使用青蓝；K⁺使用暖金；刺激使用珊瑚红。
- 层级：主膜视图边界最明确；曲线和解释为辅助观察区；底部控制坞保持稳定。
- 卡片：减少阴影层数，使用清楚的边框、圆角和分区标题；避免每个区域都使用相同视觉重量。
- 按钮：明确区分主按钮、分段选择、次级按钮和开关；状态变化不改变尺寸，避免布局抖动。
- 文本：桌面正文不小于 12 px；手机核心说明不小于 11 px；所有普通文本对背景至少达到 4.5:1。

## 无障碍与性能

- 保留语义化 `main`、`header`、`nav`、`section`、`fieldset` 和所有现有 ARIA 标签。
- 键盘焦点清晰可见；所有可操作控件保持合理点击区域。
- `prefers-reduced-motion: reduce` 下停止非必要漂移、脉冲和过渡，但保留离子方向、通道状态和阶段信息。
- 只使用 CSS Grid/Flex、Canvas 和现有粒子 DOM，不新增高成本滤镜或额外粒子数量。

## 测试与验收

自动化测试必须覆盖：

- 原版仍使用原布局，且不加载/匹配美化布局样式。
- 美化版存在独立工作区、阶段轨道、膜主视图、同步观察区和控制坞。
- 桌面和手机断点使用不同布局，不是简单纵向堆叠。
- 所有美化生产选择器保持作用域。
- 播放、阶段播放、拖动、刺激强度、速度和对比功能继续通过现有测试。

浏览器验收必须覆盖 1440 × 900 和精确 390 × 844：

- 文档无水平或垂直溢出。
- 标题/状态、曲线、膜与通道、阶段原因和控制台同时位于一个视口。
- Na⁺ 内流和 K⁺ 外流均能看到粒子穿过对应开放通道。
- 全流程与每个分阶段播放都有动画，曲线与原因同步。
- 原版视觉和功能不变。
- 控制台无错误或警告。

## 成功标准

学习者第一眼先看到膜与离子机制，同时能在旁边或上方观察曲线形成；桌面和手机都能在一个视角内完成播放、阶段切换和刺激选择。美化版在布局、信息层级和操作方式上明显区别于原版，而不是仅更换颜色与阴影。
