膜电位动态实验台——独立网页包
==========================

本包只包含膜电位动态交互模型。

直接查看成品（Mac）
------------------
1. 解压整个文件包。
2. 双击“打开网页.command”。
3. 浏览器会自动打开 http://localhost:8080 。
4. 查看结束后，关闭命令窗口即可停止网页。

如果系统首次阻止打开：请右键点击“打开网页.command”，选择“打开”。

使用源码运行（Windows、Mac 或 Linux）
-------------------------------------
安装 Node.js 20.9 或更高版本，在本文件夹依次运行：

  npm install
  npm run dev

重新生成静态网页：

  npm install
  npm run build

生成的网页位于 out 文件夹。
